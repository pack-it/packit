# Unlink

The `unlink` command has the following command line syntax:<br>
`pit unlink <PACKAGE-NAME>`

## Basic unlink
The `unlink` command unlinks a package, using the following syntax:<br>
`pit unlink <PACKAGE-NAME>`

### Examples
To unlink a package called `foo`, use:<br>
`pit unlink foo`

Note that only a package name should be used.
